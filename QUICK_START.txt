🔧 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

Can't access http://localhost:8787?
  1. Check service is running:
     sudo systemctl status rstudio-server

  2. Start if not running:
     sudo systemctl start rstudio-server

  3. Check port is listening:
     sudo netstat -tlnp | grep 8787

Port 8787 in use?
  sudo lsof -i :8787          # Find what's using it
  sudo kill -9 <PID>          # Kill the process

  Or change port in: /etc/rstudio/rserver.conf

Login issues?
  • Verify system user account exists
  • Check credentials are correct
  • Try creating new system user:
    sudo useradd -m newuser
    sudo passwd newuser

💡 NEXT STEPS AFTER INSTALLATION
────────────────────────────────────────────────────────────────────────────────

1. Login to http://localhost:8787

2. Create New Project:
   File → New Project → New Directory

3. Create R Script:
   File → New File → R Script

4. Start coding! Example:
   library(tidyverse)

   data <- data.frame(
     x = 1:10,
     y = rnorm(10)
   )

   ggplot(data, aes(x, y)) +
     geom_point() +
     geom_smooth(method = "lm") +
     theme_minimal()

5. Advanced: Create RMarkdown Document:
   File → New File → R Markdown
   Great for reports, analysis, presentations


🔐 SECURITY NOTES
────────────────────────────────────────────────────────────────────────────────

• Change default RStudio Server port if exposed to internet
• Use strong passwords for user accounts
• Use SSH tunneling for remote access:
  ssh -L 8787:localhost:8787 user@server.com

• Enable firewall rules:
  sudo ufw allow 22/tcp  (SSH)
  sudo ufw allow 8787/tcp (RStudio - only if needed)

• Use HTTPS/SSL for production setups
• Run RStudio Server in containers for isolation
